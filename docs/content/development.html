Daily commands

make fmt        # format Go code
make check      # vet, race-enabled tests, format check, build
make build      # produce bin/server
make docs       # build docs/public with Hugo
make docs-serve # preview on http://localhost:1313/

Go tests use the standard testing and httptest packages. Add table-driven configuration tests and handler tests near the implementation. For an individual package, run go test -race ./internal/web.

Dependencies and updates

The service uses only the Go standard library, so there is no go.sum yet. Use go get module@version and go mod tidy when adding dependencies, and commit both module files. Docker copies both automatically.

Dependabot checks Go modules, SHA-pinned GitHub Actions, and Docker images weekly. Review updates rather than automatically merging them. Go starts at 1.27.4 and Hugo at 0.169.0, the latest stable releases checked for this first pass.

When updating Go, align go.mod and the Dockerfile tag/digest. When updating Hugo, update the version and official release SHA-256 in .github/actions/setup-hugo/action.yml; Hugo's binary is not managed by Dependabot. Install that same Hugo version locally from the official release, checking its checksum before running it.

Documentation

Content lives in docs/content/. Existing pages use HTML with TOML front matter; Hugo also supports Markdown pages. Add a title and weight to include a page in navigation. Layouts and CSS are local, avoiding theme/submodule drift. CI builds the site with a project subpath to check GitHub Pages compatibility.

Continuous integration

Pushes and pull requests run Go checks, build and smoke-test the container, and build the documentation without publishing. CI has read-only repository permissions and does not receive deployment credentials. The setup-go download cache is disabled while there is no dependency checksum file.
