Run locally

Install the Go version specified in go.mod (currently 1.27.4). GNU Make is optional; the commands in the Makefile can also be run directly.

make run
# In another terminal:
curl http://localhost:8080/healthz

Visit http://localhost:8080/ for the embedded starter page. Stop the server with Ctrl+C.

Configuration

The native binary reads exported environment variables, not dotenv files.

VariableDefaultPurpose
APP_ADDR:8080Listen host and numeric port (1–65535)
APP_LOG_LEVELinfodebug, info, warn, or error
APP_PORT8080Compose host port only
 
APP_ADDR=127.0.0.1:9000 APP_LOG_LEVEL=debug go run ./cmd/server

The native default binds all interfaces for container compatibility. Use a loopback address for local-only development. Compose exposes only loopback by default.

Make it yours

  1. Create a repository from this template and choose its visibility deliberately.
  2. Change the module path with go mod edit -module=github.com/OWNER/PROJECT, then update imports in cmd/server/.
  3. Update the README, templates, docs titles and release project names.
  4. Review the license and retain notices for any reused code.
  5. Install Node 24, Make and a C compiler; run make setup, then make check, make docs, and docker compose up --build.
  6. Review repository Actions, branch protection, Dependabot, package visibility, and Pages settings. Publishing remains disabled until explicitly enabled.
